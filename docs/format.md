# 走行データの形式（ecorun、版 1）

ロガー（EcoLogger）と解析アプリの境目は、この形式だけ。ロガー側が書き出し、解析アプリはこれだけを読む。
ロガーの中身（車のCANの読み方・周の数え方・通信）はこの形式に出さない。出すのは**物理量になった値**と、ロガーが出した結果（周のタイム）だけ。

## 1. 全体

走行1回ぶん（またはその一部）を、名前が `.ecorun` で終わるフォルダー1つにまとめる。

```
SUGO_20261108_31-33.ecorun/
  session.json        決めごと（時刻の基準・チャンネルの一覧・周・動画・コース）
  channels.csv.gz     チャンネルの値（時刻ごと）
  gnss.csv.gz         測位の解（解が出た時刻ごと）
  video/01.mp4        動画（無くてもよい。何本でもよい）
```

- 文字はすべてUTF-8。CSVの区切りはカンマ、1行目は見出し。`.csv.gz` はgzipで縮めたCSV（`.csv` のままでもよい。読む側は両方読めること）。
- **時刻はすべて `t`（秒）で書く。`t` は `session.json` の `t0_utc` からの経過秒**。チャンネル・測位・周・動画の対応表は、全部この同じ `t` を使う。
- フォルダーの中のファイルの名前は、`session.json` に書いたものを使う。読む側は、フォルダーの外を指す名前（`..` や絶対パス）を受け付けない。

## 2. session.json

```json
{
  "format": "ecorun",
  "version": 1,
  "created_utc": "2026-11-14T12:00:00Z",
  "created_by": "EcoLogger export_session 1",
  "title": "SUGO 2026-11-08 31〜33周",
  "t0_utc": "2026-11-08T03:05:12.300Z",
  "duration_s": 280.5,
  "clock": "gnss",
  "source": {"device": "EcoLogger V2", "log": "LOG_20261108T005746Z_271343d4"},
  "course": {
    "name": "スポーツランドSUGO 国際レーシングコース",
    "line": {"lat": 38.1423181, "lon": 140.7779443, "bearing": 97.5, "width_m": 50.0},
    "sectors": [{"lat": 38.1392767, "lon": 140.7787425, "bearing": 71.0, "width_m": 30.0}]
  },
  "channels_file": "channels.csv.gz",
  "channels": [
    {"name": "RPM", "unit": "rpm", "kind": "number"},
    {"name": "ClutchDisengaged", "unit": "", "kind": "state"}
  ],
  "rate_hz": 50,
  "gnss_file": "gnss.csv.gz",
  "gnss": {"source": "sd", "rate_hz": 10},
  "laps": [
    {"lap": 31, "start": 3.1, "end": 89.8, "time_s": 86.712, "sectors": [21.3, 30.1, 35.3]}
  ],
  "videos": [
    {"file": "video/01.mp4", "sync": [[0.0, -1.42], [1.16, -0.26]]}
  ],
  "notes": []
}
```

| 項目 | 必須 | 中身 |
|---|---|---|
| `format` | ○ | いつも `"ecorun"` |
| `version` | ○ | この文書の版（整数）。読む側は知らない版を開かない |
| `created_utc`・`created_by` | | 書き出した時刻と道具 |
| `title` | | 画面に出す名前 |
| `t0_utc` | ○ | `t = 0` のUTC（ISO 8601、末尾 `Z`） |
| `duration_s` | ○ | チャンネルの最後の `t` |
| `clock` | ○ | `"gnss"`＝時刻を測位の時計に合わせてある。`"host"`＝測位が無く、ロガーの時計のまま（数分ずれていることがある） |
| `source` | | どのロガーのどの記録から書いたか（見るだけ。読む側はこれで動きを変えない） |
| `course` | | コースの名前と、コントロールライン `line`・セクターの線 `sectors`（中心の緯度経度、線の向き `bearing`＝北から時計回りの度、幅 `width_m`）。`line` は `laps` の始まり・終わりを出した線。分からなければ書かない |
| `channels_file`・`channels` | ○ | チャンネルのCSVと、その列の説明（下の3章） |
| `rate_hz` | | チャンネルを書いた間隔の目安。**読む側は等間隔と決めつけない** |
| `gnss_file`・`gnss` | | 測位のCSV（4章）。`source` は `"sd"`（受信機の解を全部）か `"logger"`（ロガーの記録から拾った解）。測位が無ければ書かない |
| `laps` | ○ | 周（5章）。周が無ければ空の配列 |
| `videos` | ○ | 動画（6章）。無ければ空の配列 |
| `notes` | | 人が読むための覚え書き（文字列の配列） |

## 3. チャンネル（channels.csv）

- 1列目は `t`、2列目からが `channels` に書いた順のチャンネル。見出しは `name` と同じ。
- `t` は増える一方（同じ値が続かない）。
- 値が無い所は空欄。数は小数点の `.` で書く。
- `channels` の1つ：
  - `name`：見出しの名前。英数字と `_` だけ
  - `unit`：単位。`km/h`・`rpm`・`%`・`V`・`°C`・`m/s²`・`°/s`・`°`・`g` など。単位の無いものは空の文字列
  - `kind`：`"number"`（量。間を線でつないでよい）か `"state"`（状態。0/1など。間は前の値のまま）
  - `label`（無くてもよい）：画面に出す名前
- 加速度の向き（書き出す側が守る）：`LongAccel` は加速が＋、`LatAccel` は右が＋、`VertAccel` は上が＋（重力を除いた値）、単位 `g`。

## 4. 測位（gnss.csv）

列はこの順：

| 列 | 単位 | 中身 |
|---|---|---|
| `t` | 秒 | **受信機がその解を出した時刻**（ロガーに届いた時刻ではない） |
| `lat`・`lon` | 度 | WGS84。北・東が＋ |
| `alt_m` | m | 高さ（無ければ空欄） |
| `speed_kmh` | km/h | 受信機の速さ |
| `heading_deg` | 度 | 進む向き（北から時計回り） |
| `sats` | | 使った衛星の数 |
| `hacc_m` | m | 水平の精度の目安（無ければ空欄） |

- **書くのは本物の解だけ**。ロガーが前の値を持ち続けた行や、補って作った点は書かない（間を補うのは読む側）。
- `t` は増える一方。

## 5. 周（laps）

| 項目 | 中身 |
|---|---|
| `lap` | 周の番号（ロガーの通し番号。1からとは限らない） |
| `start`・`end` | 周の始まりと終わりの `t`＝**コントロールラインを越えた時刻**（線の手前と先の測位から、線の上に来た瞬間を補って出す。測位の時刻で） |
| `time_s` | ロガーが出したタイム（秒）。公式の計測ではない |
| `sectors` | セクターのタイム（秒）の配列。無ければ空の配列。分からないセクターは `null` |

- **続いた周は境目が同じ**：ある周の `end` と次の周の `start` は同じ値。`end − start` は `time_s` と数ms以内で合う。
- セクターの境目は `start` にセクターのタイムを順に足した時刻。
- 線を越えた時刻を書き出す側が出せなかった周（測位が抜けた、など）は、ロガーが周を数えた時刻を `end`、`end − time_s` を `start` にしてよい。そのときは線を越えた時刻より数十〜百数十ms遅いので、どの周がそうかを `notes` に書く。
- `laps` は「ロガーの数え」。読む側は、ここに書かれた周をそのまま使ってよい。別のコントロールライン（コースの資料の線など）で、測位から周を切り直してもよい。
- 書き出した範囲に全部が入っていない周は書かない。

## 6. 動画（videos）

- `file`：動画のファイル（フォルダーからの相対）。MP4（映像H.264・音AAC）。
- `sync`：`[動画の秒, t]` の組の配列。動画の秒は、その動画を頭から再生したときの秒（`<video>` の `currentTime`）。
  - 組は動画の秒の順に並べ、どちらも増える一方。読む側は組の間を線形に補う。組の外側は使わない（その時刻の動画は無いものとする）。
  - 組は1秒に1つくらい。録画の時計とロガーの時計が少しずつずれても合うよう、1本につき2つ以上は書く。
- 動画どうしの時間が重なってもよい（読む側は、その時刻を含む動画を選ぶ）。

## 7. 版を上げるとき

- 項目を足すだけ（読む側が知らない項目を飛ばせば済む）なら、版はそのまま。
- 意味を変える・項目をなくすときは `version` を上げ、この文書に違いを書く。
